# Contributing

**English** | **[简体中文](#贡献指南)**

Thanks for helping grow this list. [Awesome Jev](README.md) is a community catalog of things built with (or clearly inspired by) [Jev](https://docs.typesafe.ai/introduction).

This repository is unofficial and not affiliated with TypeSafe AI.

## What belongs here

- Open-source applications, libraries, MCP servers, skills, research models, and substantial demos that use Jev / the TypeSafe System One API in a meaningful way.
- Independent models or tools that deliberately match Jev's *interface* (state + typed options → probabilities), marked as unofficial.
- High-signal articles, talks, and cookbooks that help people build.

Please skip:

- Closed-source products with no public write-up or demo.
- Trivial “hello world” gists that only repeat the official quick start.
- Marketing posts, waitlist spam, or content that does not mention Jev / TypeSafe System One.
- Anything that is just a wrapper around someone else's already-listed project.

## How to add an item

1. Fork this repo.
2. Add the project to **both** [README.md](README.md) and [README_zh.md](README_zh.md), in the same section and the same relative position. Official items stay first; community items go with similar projects.
3. Use this format:

   ```markdown
   - [Project Name](https://github.com/org/repo) - One sentence: what it does and how it uses Jev.
   ```

4. Keep the description short. Link the repo or canonical page, not a tracking URL.
5. If the project is unofficial, say so in the blurb.
6. Open a pull request. In the PR body, include: what the project is, how it uses Jev, and why it is interesting.

New sections are fine when a category has three or more items.

## Style

- American English in `README.md`; Simplified Chinese in `README_zh.md`.
- Sentence case. No trailing period unless the description has multiple sentences.
- No emoji in list entries. No star-count badges (they go stale).
- Do not paste secrets, API keys, or waitlist invite codes.

## Related

If you are not sure a project fits, open an issue first.

# 贡献指南

感谢帮忙扩充这份列表。[Awesome Jev](README_zh.md) 收集基于（或明确受启发于）[Jev](https://docs.typesafe.ai/introduction) 的社区项目。

本仓库为非官方整理，与 TypeSafe AI 无隶属关系。

## 什么适合收录

- 真正用到 Jev / TypeSafe System One API 的开源应用、库、MCP 服务、skill、研究模型，以及有分量的 demo。
- 刻意对齐 Jev **接口**（state + 类型化选项 → 概率）的独立模型或工具，需标明非官方。
- 对动手有帮助的高质量文章、演讲和 cookbook。

请不要提交：

- 没有公开说明或 demo 的闭源产品。
- 只是复述官方 quick start 的 hello world。
- 营销软文、候补名单广告，或完全不涉及 Jev / TypeSafe System One 的内容。
- 只是给列表里已有项目再包一层的包装器。

## 如何添加条目

1. Fork 本仓库。
2. **同时**改 [README.md](README.md) 和 [README_zh.md](README_zh.md)，放进同一章节、同一相对位置。官方条目靠前，社区条目跟同类项目放在一起。
3. 格式：

   ```markdown
   - [项目名](https://github.com/org/repo) - 一句话：它做什么，以及怎么用 Jev。
   ```

4. 简介保持短。链到仓库或权威页面，不要用带追踪参数的链接。
5. 非官方项目请在简介里写明。
6. 提交 PR。正文说明：项目是什么、如何使用 Jev、为什么值得收录。

某一类满 3 个条目时，可以新开章节。

## 文风

- `README.md` 用美式英语；`README_zh.md` 用简体中文。
- 条目描述用短句。不要在列表项里用 emoji，也不要加星标数徽章。
- 不要粘贴密钥、API key 或邀请码。

不确定是否适合收录时，可以先开 issue。
